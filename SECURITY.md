# Security Policy

## Supported version

Only the latest version on `main` is supported.

## Reporting

Please use GitHub private vulnerability reporting when available. Do not publish credentials, private repository data, personal information, or exploit details in a public issue.

## Scope

The demo is local-only, reads deterministic fixtures, and requires no credentials. Future adapters must remain read-only by default, use explicit host allowlists, bounded timeouts, and sanitized output.
